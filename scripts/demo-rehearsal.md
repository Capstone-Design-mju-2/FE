# 추천 → 품절 대안 → 체험 주문 시연

## 사전 준비

1. `npm ci` 후 `npm run dev`를 실행한다. 목업 시연은 `VITE_USE_MOCK=true`로 진행한다.
2. 브라우저에서 `/?mock=alternatives#chat`을 연다. 이 경로는 BE와 LLM 없이 고정 응답을 보여 준다.
3. 발표 전에 아래 순서를 두 번 반복하고, 화면 공유 해상도에서도 카드와 주문 패널을 확인한다.

## 발표 순서

1. 예시 질문을 보내 추천 카드 3개와 각 재고 상태를 보여 준다.
2. 첫 카드의 **주문**을 눌러 모든 옵션이 품절된 상태를 확인한다.
3. **같은 조건의 대안 보기**를 눌러 새 추천을 받는다. 처음 상품이 새 결과에서 빠졌는지 확인한다.
4. 주문 가능한 대안 카드의 **주문**을 눌러 옵션과 수량을 고르고 **주문하기**를 누른다.
5. 완료 화면의 주문 번호·옵션·수량·합계와 마이페이지의 체험 주문을 보여 준다. 목업 주문은 서버에 저장되거나 재고를 차감하지 않으며 새로고침하면 사라진다.

## 실서비스 전환 점검

- FE Gateway PR #27과 BE Gateway PR #45의 피부 분석 경로가 반영된 버전에서 개발 프록시를 확인한다.
- BE 옵션 조회와 주문 `requestId` 멱등 처리 완료 후, 실제 재고 차감·409 품절·대안 재검색을 별도로 검증한다.
- 팀 서버의 유효한 인증 정보와 LLM 설정을 확보한 뒤 추천 이유, 리뷰 근거, 검색 품질을 확인한다. 현재 목업 시연은 이 검증을 대신하지 않는다.
